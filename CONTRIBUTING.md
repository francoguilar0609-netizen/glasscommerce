# Contributing to GlassCommerce

Thank you for helping improve GlassCommerce.

1. Search existing issues before opening a new one.
2. Create a focused branch from `main`.
3. Keep changes small and document user-visible behavior.
4. Run `npm run lint` and `npm test`.
5. Open a pull request that explains the problem, approach and validation.

Never commit credentials, API keys, customer information or payment data.
Security reports should follow `SECURITY.md`, not a public issue.

Pull requests require maintainer review. Generated code must be understood,
tested and attributed where required; contributors remain responsible for the
code they submit.
